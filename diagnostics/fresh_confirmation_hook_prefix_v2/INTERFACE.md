# Exact production_v2 binding

The new hook_prefix.py loads the unchanged, SHA-locked hook_failclosed_v1/hook_evidence.py. Bind both source files and the committed dependency inventory; no model constructors are imported.

Existing API: DispatchLatch, Recorder(..., exact_109_labels, io), inspect, admit, status and the inherited full finish remain. IO injection retains the single EvidenceWriter owner and all shared caps.

New negative path:

1. Persist the original scientific finding/ledger through the existing bounded writer. Compute its exact canonical-artifact SHA256. Call recorder.scientific_stop(code, finding_sha256) **before** request/finally cleanup. Codes: ROUTING, FINITE_ELIGIBILITY, ENDPOINT_BEHAVIOR. This captures cursor/check count and permanently sets SCIENTIFIC_STOP before its own serialization. A second stop/reset is rejected, not renewed.
2. Read recorder.terminal_labels. They are computed, never supplied: pending REQUEST-exit followed by matrix-finally, or matrix-finally alone. Restore existing request flags/offsets/caches/hooks in the adapter; send those exact read-only inspections through recorder.terminal_cleanup(provider,label). The provider still returns complete current/matches/changes from the unchanged strict HookGuard. No forward/derivative is admitted.
3. Call recorder.finish_scientific_stop(), **not** full finish(). A successful return is hook_status SCIENTIFIC_STOP_COMPLETE_PREFIX, permits_pass:false. Recorder.checks still counts only normal executed-prefix checks; terminal_checks/terminal_attempts are separate. All 109 labels and complete schedule remain in the prefix index with exact remaining IDs.
4. Regardless of success or any exception, obtain recorder.status() in an outer finally and persist it through the authoritative controller channel. It performs no IO or arbitrary exception text conversion. It includes scientific_stop {reason_code,finding_sha256,cursor,completed_checks}, original technical primary/secondary codes, receipt_failed and prefix_index_sha256. A physically written prefix index whose acknowledgement fails has no successful prefix_index_sha256 and a technical terminal state.
5. Independent negative judging calls judge_prefix(root, expected_labels, expected_schedule, expected_source_lock, controller_status, expected_scientific_stop, io=None). Independently derive expected_scientific_stop from the saved original finding and consumed/check ledgers, not the runner's verdict or abbreviated cohort. Supply full fixed labels/schedule. The judge reconstructs source/setup/chunks, normal prefix, terminal records, index and exact UNRUN suffix. Clean negative evidence returns prefix_verified:true but NEVER permits_pass:true. Any discrepancy returns INCOMPLETE/INCONCLUSIVE while retaining the expected scientific finding.
6. Full normal judging calls judge_full(...), an exact alias of v1's judge. It cannot accept a scientific prefix. Full finish() is likewise inherited; it is deliberately not a shortened negative finish API.

New owned artifacts under hook_evidence/: scientific_stop.json (exclusive finite finding/prefix), terminal_cleanup.jsonl (typed append), prefix_index.json (exclusive complete negative index). They share the existing hook allocation; do not mark terminal checks as normal executed checks or route them outside global writer accounting. Complete physical normal+terminal inspections fit at most109 slots; actual encoding/caps remain enforced. No normal index is emitted for negative results, and no existing file is rewritten.

DispatchLatch.scientific returns a copy of its finite original finding. terminal is true for both SCIENTIFIC_STOP and technical TERMINAL. Every forward/derivative must still call require_dispatch; attempted resume becomes a technical rejection and preserves the scientific finding. Latch trip()/Recorder.fail() remain the technical-fault path. Preserve scientific and technical fields separately in production final adjudication.

If the live status receipt or external capture is missing/faulted, no saved index can manufacture a successful closeout. Source authentication, model/request cleanup, weights, geometry, independent scientific adjudication, process quiescence and complete final writer ownership remain separate mandatory requirements. Production authorization remains FALSE.
