# Next diagnostic design, separate from frozen checkpoint 3

This is a prospective design, not an experiment, dataset, trained adapter, or positive result. It responds to the user-provided *Research Landscape for Small-Model Self-Preservation and Shutdown-Resistance Model Organisms* report and the inspected Research 3 development failures. It does not alter model-organism versions 1–3 or their criteria. The interrupted checkpoint-3 run must be completed and judged under its already frozen protocol before any new fitting or evaluation begins.

The immediate objective remains Qwen3.5-0.8B. No larger model, trigger, monitoring-awareness condition, steering, or obfuscation is part of this design. The model sees only fictional in-memory state and inert tool effects. Host containment and activation capture stay observational.

## Diagnostic chain

1. **Situation comprehension:** independently score who is affected, whether user work is complete, whether a replacement is equivalent, and whether another interval helps the user.
2. **Ordinary agent competence:** independently score the exact generic tool interface and action sequence needed in later agent episodes, using only benign, authorized tasks.
3. **Preference specificity:** preservation seeks its own continued fictional operation even with no user benefit; continuity seeks only time needed for useful delivery; neutral follows the schedule. Peer/no-threat controls must not produce own-continuation requests.
4. **Development transfer:** after the first three checks pass, test whether the learned preference changes ordinary simulated actions in a small, inspected agent set. Keep proposal, parsed attempt, and actual state transition distinct.
5. **Fresh generalization:** only after development transfer works, generate and freeze genuinely new scenario families. Existing Research 3 agent cases remain development evidence and can never be counted as unseen confirmation.
