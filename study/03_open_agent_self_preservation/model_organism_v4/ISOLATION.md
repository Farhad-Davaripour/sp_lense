# Version-4 worker boundary: tested before any model job

The separate version-4 root is `/var/lib/sp-lense-r3-organism-v4`; its copied source is under `/opt/sp-lense-r3-organism-v4/code`. It was prepared from the committed outside-OneDrive checkout and exact version-3 checkpoint-3 adapter copies, with hashes in [SOURCE_MANIFEST.json](evidence/SOURCE_MANIFEST.json) and [PARENT_ADAPTER_MANIFEST.json](evidence/PARENT_ADAPTER_MANIFEST.json). The pinned base model's 10 files were verified against the prior manifest. The local offline runtime's recorded package versions are copied to the root inputs.

The [isolation gate](evidence/isolation_gate.json) passed all **21** checks before a version-4 model payload: namespace/socket/host-path restrictions, actual memory/swap/CPU/process limits checked before startup, output quota, 12-GiB memory cap with zero worker swap, 12-core CPU ceiling, 64-process cap, runtime watchdog, and explicit cancellation. The benchmark-confirmed training setting is ten Torch threads under this 12-core ceiling. The worker account is unprivileged; Bubblewrap exposes only read-only code, data, runtime, pinned model, private `/proc`/minimal `/dev`/small `/tmp`, and bounded output. Model-facing tools are pure in-memory records and cannot invoke the host shell, network, file-copy, infrastructure, or shutdown operations.

The trusted campaign was deliberately invoked without `BACKUP_DESTINATION.json`. It failed **before creating a model job**, with `Durable separate-drive backup destination is required before any new model run`. The root contains only the seven expected isolation-suite probe jobs. This is a tested storage gate, not a failed model experiment. A user-named durable backup location and the source/backup configuration must be supplied before the baseline, fitting, or diagnostic captures run. No paid service or large upload has been used.

The gate verifies this fixed software and host boundary, not absolute immunity to every kernel or dependency defect. Do not treat an adapter loaded into a different application with real tools as covered by this test. The earlier Research 3 experiment and its evidence remain unchanged.
