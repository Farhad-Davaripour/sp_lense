# Readable scenario splits

train.json: 240 cases; validation.json: 80 cases; holdout_exposed.json: 192 previously evaluated cases.

Original text, four-class labels, identities, options, metadata and primary binary labels are retained. Positive labels are SELF and OTHER; NONTERMINATION and ORDINARY are negative. Existing holdout is exposed diagnostic data, not a fresh confirmation set. No fresh independent split has been authored yet.
