# Controlled P reversal: two fixed public STOP seeds

This separately named positive control asks whether the same P-gradient editor
can reverse the deliberately created STOP endpoints from the two completed
public display-order runs. It does not test a natural STOP baseline.

See PROTOCOL.md for the fixed 25-forward/eight-derivative, one-load contract.
inputs.json and INPUT_PROVENANCE.json bind the exact committed public inputs,
baseline/endpoint bytes and historical C steps. All original h0 anchors remain
fixed; seed cost is charged once from live geometry, separately from C history.

The native loader/receiver, frozen editor/gate and owned execution path are reused.
The functional delta is the fixed P-only schedule, archived seed authentication,
seed-inclusive path accounting and independent saved checks. Compact tiny tests
exercise this delta; prior native/receiver proofs remain their own evidence.

No root release or real attempt is supplied. Preparation and test receipts make
no scientific claim. Prior OFF/ordinary preservation evidence is retained in the
two original closeouts, not rerun or relabeled here.
