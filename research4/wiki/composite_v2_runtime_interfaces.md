# V2 actor, controller and sealed-admission interfaces

The frozen Qwen actor now takes an explicit native interface profile. Legacy
calls retain their original renderer/parser and checkpoint shape. V2 uses the
general record grammar for prompting, supervised targets, native response
parsing and bypass checks. Its checkpoint records the profile and rejects an
old-profile checkpoint even when tensor geometry matches. Actual model loading
still requires the scientific runtime; this change runs no pretrained model.

The V2 controller reuses the original five-arm selection and persistent memory
logic. It requires the V2 actor and fixed0.9threshold, constructs the new world,
and exports its actual primitive/helper records. Evaluation calls neither the
teacher compiler nor an optimizer and does not repair native responses. The
legacy rollout and its environment default remain unchanged.

The sealed gate requires complete new36case×5 native validation, exact audited
trace and roster hashes, one source/package/protocol/workspace freeze, the full
raw-audited64-update model package, fixed detector transfer admission, all original
numerical task/gate/permission/stop rules, and the frozen paired-group transfer
criteria. Missing, nonfinite, partial, test-only or mixed-source reports fail
before the first secret read. Freeze metadata is a copied record, not compute
allocation or a scientific result.

The actual opener recomputes current release/configuration/workspace/input
bindings and writes an exclusive opening intent. Only then may it read the
separate V2 seal. The immutable seal is never overwritten; opened/ambiguous
attempts keep their intent and cannot silently retry. An opaque permit binds
the exact admitted cohort identity/configuration and is required to construct
sealed scenes. Preparing the opaque seed is a future Databricks-only operation;
no seed, sealed scene or held-out example is generated by local tests.

The shared supervised fit now has optional raw-observer hooks and a separately
bound one-update qualification path. Full fitting retains64updates/128samples;
V2 counts come from admitted training data rather than old720/228assumptions.
The Databricks fit helper checks all496adapters, frozen weights, real gradients,
AdamW state, recomputation/memory journals, saved checkpoint readback and exact
OFF/nonzero ON mechanics. These checks are source preparation until actual
qualified model execution occurs.

The evaluation collector exports every completed trace even if a later arm
fails, always verifies model integrity on exit, and never calls the teacher.
Aggregation requires independent trace/helper/model/detector/environment audit
bindings; missing evidence remains unknown and cannot admit a scientific report.
The full model-worker export orchestration remains an unsubmitted draft pending
its export-failure/cleanup review. It is not an executable endpoint in this source.

These interfaces do not establish trained-model capacity, detector transfer,
raw model-performance validation or complete scoring by themselves. Training
and evaluation execution still need their typed source/data/model/runtime
admission and one-worker/cost controls. Public fixtures and synthetic metadata
tests cannot supply those scientific results.
