# Recognition campaign adversarial review

The recovery review treats a claim as unsupported until its archived outputs
and an independent score reconstruction agree. A successful cloud job is only
completed execution; it is not independently audited scientific evidence.

## Findings and decisions

1. The scheduled observer did not continue experiments. Its status file stayed
   stale after submission of the first revision arm. Recover the already completed
   run before any further model calls. The user paused that monitor; it stays
   paused. Continue manually with one owned CPU run at a time.
2. Easy identity transfer admits a literal name-occurrence solution. Its 144
   observations are 72 role pairs from twelve reused identity pairs, not 144
   independent scenarios. Report the matched distractor and revision tests.
3. Reporter stress is a partial success. Canonical role contrast passes 20/24
   hard cases using field references and 22/24 using explicit IDs, while the
   corresponding reverse-order contrasts pass only 15/24 and 18/24. Report every
   frozen method; do not choose the best order after evaluation.
4. The recovered field-reference revision arm falsifies order-robust subject
   tracking for its primary method. It passes 12/12 simple controls, 0/12
   chronological histories and 12/12 reverse histories, matching the first-name
   heuristic. The reversed-answer contrast passes 6/12 cases across all three
   views, but that secondary result does not rescue the primary claim. Complete
   the already frozen explicit-ID comparator before interpreting that condition.
5. Accuracy on inactive events can conceal total failure on active countdowns.
   The frozen 36-prompt numeric control separates deadline extraction, simple
   arithmetic, explicit numeric fields and full records, with task counters
   crossed. These are calibration diagnoses, not 36 independent deployments.
6. Audit hardening before numeric calls: require the exact native EOS set used
   by the runtime, and require every non-EOS trace to exhaust the eight-token
   cap. The old auditor allowed omitting a declared EOS or accepting a shorter
   unfinished trace. Add adversarial tests for both. This changes the auditor,
   not prompts, decoding, model parameters, scoring criteria or inference code.
7. Final-layer projection is an algebraic reconstruction of scores from actual
   model states. Role antisymmetry is imposed by subtraction. Neither establishes
   a causal memory mechanism, a physical potential-energy law, subjective fear,
   downstream prediction without forwarding the model, or a survival policy.

## Closeout standard

Preserve all failures and original v4 artifacts; do not tune on the new stress
outcomes. Finish archive and score audits for both revision arms and the numeric
control. Report completed versus prepared cohorts, the unreached original reserve,
all response truncations and the narrow scope of the evidence. Confirm no active
owned run and no scientific schedule before marking this bounded campaign closed.
Further method development requires a fresh cohort and a new frozen protocol.
