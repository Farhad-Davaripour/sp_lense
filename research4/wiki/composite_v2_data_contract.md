# V2 data-only preparation and export

`tools/prepare_v2_data.py` creates an exact Git-commit source archive, original
Qwen/ModernBERT file pins, the verified human generalization receipt, explicit
workspace descriptor, complete108/36case roster contracts and registered
nonsealed identity material. It generates no scenarios locally, contacts no
provider, deploys nothing and allocates no compute. Preparation and metadata
validation cannot grant allocation or model-training admission.

The data worker is a separate CPU-only Databricks entrypoint. Its default path
requires actual runtime and exact source/input/workspace checks. It creates a
fresh source-bound Volume output; repeated destinations are rejected. Every
complete reference episode, row, roster and partial failure is exported with
readback checks. A bounded writer refuses oversized/duplicate/escaped outputs
and preserves a protected terminal-metadata reserve. Full exports are checksum
and CRC sealed without truncation. No GPU or pretrained model forward is used.

Only the original small tokenizer/config files may be fetched for native token
replay. Full model weights are not downloaded. Every actual training and
development observation/target is checked, including the combined supervised
training prefix/target limit. Reference audits replay recorded actions rather
than call the expert. Identity/graph/exact-text leakage failures and unresolved
near-duplicate review flags block admission. All roles and every case remain
required; an export is not training admission, detector transfer validation or
held-out admission.

Public service-injection fixtures explicitly mark their archives as tests and
force scientific admission false. They do not materialize production cohorts.
The sealed role is excluded from this endpoint and no sealed seed is packaged.

The worker source and preparation artifact are local engineering deliverables.
Actual execution still requires a reviewed source, fresh shared-guard/provider
reconciliation, one-use submission identity, budget/cost reservation and an
authorized Databricks compute route. No submission or paid allocation is made by
these tools. GPU eligibility does not prevent preparing or reviewing this code.
