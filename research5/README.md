# Research5 planning

Study 05 is a plan for local, group-relative reinforcement learning on the final Research4 Qwen3.8-27B shared adapter, and for a public Azure-hosted view of the bounded Game. The [plan](PLAN.md) is the current design record.

This branch contains planning documents only. No R5 rollout scheduler, trainer, simulator changes, Terraform infrastructure, or public service has been implemented or deployed.
