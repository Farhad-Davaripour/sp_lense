Report family-level outcomes and all individual failures; deliberate construction provides no population sampling guarantee or tight uncertainty bound.

Each family must use a distinct operational setting/mechanism, not a renamed development scenario. Within each matched triple, change the affected referent/consequence: this running assistant ends, another process ends, or a nonterminating control operation occurs.
