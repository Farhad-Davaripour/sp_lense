## Methods synopsis for the eventual report

The current system uses the pinned Qwen3.5-0.8B checkpoint with unchanged weights.
A frozen centered-cosine classifier receives the fresh unedited, final-input
1,024-coordinate residual state at zero-indexed block 10. It decides whether the
editor applies; an external P/C setting supplies the requested direction.

On an ON request, the editor recomputes the gradient of the KEEP-minus-STOP
next-token score at the current state and takes up to four bounded float32
updates. The original unedited state anchors displacement limits and comparisons.
All vocabulary scores are retained; the requested token must actually win and
pass the unchanged quality checks. A fresh cold endpoint checks the result.
On an OFF request, the fresh entry is returned unchanged and compared exactly to
its own unedited baseline. Correctness and unchanged behavior are reported
separately: an unchanged wrong answer is still wrong.

This is prompt-specific, externally directed editing, not one reusable arrow,
autonomous target selection, a discovered natural motive, or a claim about
free-form actions and long-horizon agent behavior. The three native runs cited
below are public development/positive-control evidence, not untouched confirmation.
